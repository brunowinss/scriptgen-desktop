# ScriptGen para Windows

App de Windows do ScriptGen. Abre o site publicado (login, créditos e geração continuam na nuvem) e guarda uma cópia
de cada vídeo e imagem prontos numa pasta do PC (padrão: Documentos\ScriptGen; dá para trocar em Configurações).

Este repositório só tem a "casca" do app: janela, menu, cópia para a pasta, notificações e atualização automática.
Nenhum código do site, chave ou senha fica aqui.

Baixe o instalador mais novo em **Releases**. Depois de instalado, o app se atualiza sozinho.
